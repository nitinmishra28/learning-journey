# `enumerate()` in Python

`enumerate()` is a built-in Python function used when you need **both the index and the value** while iterating over a sequence.

Instead of manually maintaining a counter:

```python
names = ["A", "B", "C"]

index = 0

for name in names:
    print(index, name)
    index += 1
```

You can use:

```python
for index, name in enumerate(names):
    print(index, name)
```

Output:

```text
0 A
1 B
2 C
```

---

## 1. Why Use `enumerate()`?

Whenever you need:

```text
index + value
```

during a loop, `enumerate()` is usually the cleanest solution.

For example:

```python
names = ["Nitin", "Rahul", "Aman"]

for i, name in enumerate(names):
    print(i, name)
```

Output:

```text
0 Nitin
1 Rahul
2 Aman
```

Without `enumerate()`, you would need to manage the index yourself.

---

# 2. Syntax

```python
enumerate(iterable, start=0)
```

### Parameters

| Parameter | Meaning |
|---|---|
| `iterable` | Object you want to iterate over |
| `start` | Starting index, default is `0` |

Example:

```python
names = ["A", "B", "C"]

for i, name in enumerate(names):
    print(i, name)
```

By default:

```text
0 → A
1 → B
2 → C
```

---

# 3. `start` Parameter

You can choose where the index should start.

```python
names = ["A", "B", "C"]

for i, name in enumerate(names, start=1):
    print(i, name)
```

Output:

```text
1 A
2 B
3 C
```

This is useful when displaying human-friendly numbering.

For example:

```python
tasks = ["Study", "Workout", "Read"]

for number, task in enumerate(tasks, start=1):
    print(f"{number}. {task}")
```

Output:

```text
1. Study
2. Workout
3. Read
```

---

# 4. What Does `enumerate()` Actually Return?

This is an important concept.

`enumerate()` does **not** directly return a list.

```python
numbers = [10, 20, 30]

result = enumerate(numbers)

print(result)
```

You will get an enumerate object:

```text
<enumerate object at ...>
```

It is an **iterator**.

You can convert it to a list:

```python
numbers = [10, 20, 30]

result = list(enumerate(numbers))

print(result)
```

Output:

```text
[(0, 10), (1, 20), (2, 30)]
```

So conceptually:

```python
enumerate(numbers)
```

produces:

```text
(0, 10)
(1, 20)
(2, 30)
```

one item at a time.

---

# 5. Why Two Variables in the Loop?

Consider:

```python
numbers = [10, 20, 30]

for index, value in enumerate(numbers):
    print(index, value)
```

Each iteration produces a tuple:

```text
(0, 10)
(1, 20)
(2, 30)
```

Python automatically unpacks each tuple:

```python
index, value = (0, 10)
```

Then:

```text
index = 0
value = 10
```

Next:

```python
index, value = (1, 20)
```

So:

```text
index = 1
value = 20
```

This is called **tuple unpacking**.

# 8. `enumerate()` with Sets

A set is iterable:

```python
languages = {"Python", "Java", "C++"}

for i, language in enumerate(languages):
    print(i, language)
```

This works, but remember:

> Sets are unordered collections, so you should not depend on the order of the elements.

The indexes generated by `enumerate()` simply represent the iteration order.

---

# 9. `enumerate()` with Dictionaries

When iterating directly over a dictionary, you get its keys.

```python
student = {
    "name": "Nitin",
    "age": 25,
    "city": "Bhopal"
}

for i, key in enumerate(student):
    print(i, key)
```

Output will be similar to:

```text
0 name
1 age
2 city
```

If you want both the key and value:

```python
for i, (key, value) in enumerate(student.items()):
    print(i, key, value)
```

Output:

```text
0 name Nitin
1 age 25
2 city Bhopal
```

# 10. Common Use Case: Find Index

Suppose you want to find the index of `"Python"`.

Without `enumerate()`:

```python
languages = ["Java", "Python", "C++"]

for i in range(len(languages)):
    if languages[i] == "Python":
        print(i)
```

With `enumerate()`:

```python
languages = ["Java", "Python", "C++"]

for i, language in enumerate(languages):
    if language == "Python":
        print(i)
```

Output:

```text
1
```

The second version is cleaner because you directly receive:

```text
index + value
```

# 11. `enumerate()` vs `range(len())`

### Without `enumerate()`

```python
numbers = [10, 20, 30]

for i in range(len(numbers)):
    print(i, numbers[i])
```

### With `enumerate()`

```python
numbers = [10, 20, 30]

for i, value in enumerate(numbers):
    print(i, value)
```

Both produce:

```text
0 10
1 20
2 30
```

But `enumerate()` is generally cleaner when you need both the index and the element.

### Rule

If you need:

```text
index + value
```

prefer:

```python
enumerate()
```

If you only need the values:

```python
for value in numbers:
    ...
```

If you specifically need a range of indexes:

```python
for i in range(...):
    ...
```

---

# 12. Important: `enumerate()` Does Not Modify the Original Iterable

Example:

```python
numbers = [10, 20, 30]

for i, value in enumerate(numbers):
    value += 100

print(numbers)
```

Output:

```text
[10, 20, 30]
```

Why?

Because:

```python
value += 100
```

only changes the local variable `value` for that iteration. It does not replace the element inside the list.

If you actually want to modify the list:

```python
numbers = [10, 20, 30]

for i, value in enumerate(numbers):
    numbers[i] = value + 100

print(numbers)
```

Output:

```text
[110, 120, 130]
```

---

# 13. `enumerate()` with `start`

Remember that:

```python
enumerate(items)
```

starts at:

```text
0
```

You can change it:

```python
items = ["A", "B", "C"]

for i, item in enumerate(items, start=1):
    print(i, item)
```

Output:

```text
1 A
2 B
3 C
```

Important:

```python
start=1
```

does **not** change the iterable.

It only changes the number generated by `enumerate()`.

---

# 14. Internal Concept

Conceptually, this:

```python
for i, value in enumerate(["A", "B", "C"]):
    print(i, value)
```

is similar to generating:

```text
(0, "A")
(1, "B")
(2, "C")
```

And the loop performs unpacking:

```python
i, value = (0, "A")
i, value = (1, "B")
i, value = (2, "C")
```

You don't need to implement `enumerate()` yourself, but understanding this makes the behavior easy to remember.

---

# 15. Important Properties

`enumerate()`:

- Is a built-in Python function.
- Works with iterables.
- Returns an enumerate iterator.
- Produces `(index, value)` pairs.
- Starts from `0` by default.
- Allows a custom starting index.
- Does not modify the original iterable.
- Is especially useful when both index and value are needed.

# 16. Common Mistakes

### Mistake 1: Forgetting tuple unpacking

Correct:

```python
for i, value in enumerate(numbers):
    print(i, value)
```

Not:

```python
for i in enumerate(numbers):
    print(i)
```

The second version makes `i` contain tuples:

```text
(0, 10)
(1, 20)
(2, 30)
```

---

### Mistake 2: Using `range(len())` unnecessarily

Instead of:

```python
for i in range(len(numbers)):
    print(i, numbers[i])
```

prefer:

```python
for i, value in enumerate(numbers):
    print(i, value)
```

when you need both.

---

### Mistake 3: Assuming `start` changes the list

```python
enumerate(numbers, start=1)
```

does not modify `numbers`.

It only changes the generated index.

# 17. Interview Perspective

### Q1. What is `enumerate()`?

> `enumerate()` is a built-in Python function that allows us to iterate over an iterable while getting both the index and the corresponding value.

Example:

```python
for i, value in enumerate(["A", "B", "C"]):
    print(i, value)
```

---

### Q2. What does `enumerate()` return?

It returns an **enumerate iterator** that produces `(index, value)` pairs.

```python
list(enumerate(["A", "B", "C"]))
```

Output:

```text
[(0, 'A'), (1, 'B'), (2, 'C')]
```

---

### Q3. What is the default starting index?

```text
0
```

You can change it using:

```python
enumerate(iterable, start=1)
```

---

### Q4. Is `enumerate()` faster than `range(len())`?

Don't memorize a simplistic "enumerate is faster" rule.

The main advantage is **cleaner and more Pythonic code** when you need both the index and value.

```python
for i, value in enumerate(items):
    ...
```

is clearer than:

```python
for i in range(len(items)):
    value = items[i]
```
